# 🏠 Home Information

iPad（とスマホ）で家族の情報をまとめて表示する、タイル式のホームインフォメーション・アプリです。
Android のホーム画面のように **タイルを自由に移動・リサイズ** でき、**スワイプで複数ページ** を切り替えられます。
タイルの中身は大きさに合わせて自動で最適化されます。

- 有料 API は一切使っていません（API キー登録も不要）
- 設定（Web サイト・API の設定、WiFi、TimeTree のログイン情報など）は **PC のローカルにのみ保存** され、Git には含まれません
- 設定・レイアウト・伝言板などは **エクスポート / インポート** できます

```
 ┌──────────── 自宅の PC（Windows） ────────────┐         ┌──── iPad / スマホ ────┐
 │  Node.js サーバー (dist/server)               │  LAN    │  Safari で表示          │
 │   ├ 画面の配信（PWA）                         │ ◀────▶ │  「ホーム画面に追加」で │
 │   ├ 外部サイトの取得・キャッシュ              │         │   全画面アプリとして使用 │
 │   └ data/ に設定を JSON で保存（ローカルのみ）│         └────────────────────────┘
 └───────────────────────────────────────────────┘
```

## はじめかた（PC 側）

1. [Node.js](https://nodejs.org/ja) 22 以上（LTS 版）をインストール
2. このフォルダの **`start.bat` をダブルクリック**

   初回はパッケージのインストールとビルドを自動で行い（数分）、サーバーを起動します。
   2回目以降は、ソースが更新されたとき（`git pull` 後など）だけ自動で再ビルドします。
   起動すると iPad から開く URL（例: `http://192.168.0.9:8580`）と QR コードが表示されます。
   **このウィンドウを閉じるとサーバーが止まる**ので、最小化しておいてください。

3. 初回は Windows ファイアウォールの確認が出るので「プライベート ネットワーク」で許可してください

コマンドで起動する場合は `npm ci` → `npm run build` → `npm start` でも同じです。

> ポート 8580 が他のアプリと重なる場合は `HOME_INFO_PORT` 環境変数で変更できます。
> 設定の保存先はこのフォルダの `data`（`HOME_INFO_DATA_DIR` で変更可）です。

### PC の起動時に自動で立ち上げる

- `scripts\register-startup.bat` をダブルクリックすると、PC にサインインしたとき `start.bat` が最小化で自動起動します（解除は `scripts\unregister-startup.bat`）
- サービスのように常駐させたい場合は `scripts/deploy-local.ps1`（pm2 を使用。下の「自宅 PC への自動デプロイ」も参照）

## スマホのリモコン

スマホで `http://（PC のアドレス）:8580/remote` を開くと、リモコン画面になります（設定 → データ管理 に QR コードがあります）。

- **ロック**：メイン画面の編集・設定をできなくして、タイルが勝手に動かないようにする（全端末にすぐ反映。解除もリモコンから）
- **画面**：iPad などの表示端末を選んで、ページ切り替え・画面を暗くする/明るくする・呼び出し・再読み込み
- **リスト**：タスクボード・買い物リスト・伝言板・コドモンのチェックをスマホから編集
- **設定**：地域・WiFi・ニュースの取得元などすべての設定（保存すると全端末に反映）

表示端末の名前は、その端末の 設定 → 表示・レイアウト →「この端末の名前」で変えられます。

## iPad での使い方

1. iPad の Safari で、サーバー起動時に表示された URL を開く（PC 画面の QR コードをカメラで読み取ってもOK）
2. 共有ボタン →「ホーム画面に追加」→ ホーム画面のアイコンから開くと全画面で表示されます
3. iPad の「設定 → 画面表示と明るさ → 自動ロック → なし」にすると常時表示できます

| 操作 | 方法 |
|---|---|
| ページ切り替え | 左右にスワイプ（下のドットをタップでも可） |
| 編集モード | タイルや空いている場所を長押し、または右下の ▦ ボタン |
| タイルの移動 | 編集モードでドラッグ。画面の端で少し止めると隣のページへ移動 |
| サイズ変更 | 編集モードでタイル右下の角をドラッグ |
| タイルの設定 | 編集モードでタイル右上の ⚙ ボタン（表示内容・アクセントカラー・背景・文字の大きさ） |
| タイル / ページの追加 | 編集バーの「＋タイル」「ページ追加」 |
| 設定 | 右下の ⚙ ボタン |

レイアウトは **端末の向き・種類ごと（タブレット横・タブレット縦・スマホ）に別々に保存** されます。
まだ作っていない向きのレイアウトは、既存のレイアウトから自動で組み直されます。

## 設定とデータの保存（PC ローカル）

| ファイル | 内容 |
|---|---|
| `data/settings.json` | 地域、WiFi、ニュースの取得元、チラシのお店、TimeTree のログイン情報、ゴミ出し、記念日、写真フォルダ、テーマなど |
| `data/layout.json` | 端末ごとのタイル配置 |
| `data/boards.json` | 伝言板・タスクボード・買い物リスト |
| `data/photos/` | フォトフレームの既定フォルダ |

- `data/` は `.gitignore` 済みで、Git には含まれません
- TimeTree のパスワードはサーバーからブラウザへは送り返しません
- 上書き前の内容は `*.bak` として 1 世代残ります

### エクスポート / インポート

設定 → データ管理 から、設定・レイアウト・伝言板などを 1 つの JSON ファイルに書き出し / 読み込みできます。
パスワード（WiFi・TimeTree）を含めるかどうかは選べます。含めないファイルを読み込んだ場合、現在のパスワードはそのまま残ります。

## 情報源について（無料・API キー不要）

| 用途 | 情報源 | 備考 |
|---|---|---|
| 天気 | [Open-Meteo](https://open-meteo.com/) | 非営利利用は無料 |
| 警報・注意報、雨雲 | 気象庁ホームページ | 2026年5月からの新しい防災気象情報（レベル付き警報）に対応 |
| 地図 | 国土地理院 地理院タイル | |
| 阪神タイガース | 球団公式サイトのニュース一覧、Google ニュース RSS | X・Instagram・LINE の公式 API は有料または非公開のため、タイルから各公式アカウントを開くボタンで対応。どうしても取り込みたい場合は自分の PC で [RSSHub](https://docs.rsshub.app/)（無料・OSS）を動かし、設定に URL を入れると取り込めます |
| ニュース | Yahoo!ニュース トピックス RSS | NHK の RSS は更新が止まっているため既定では使用していません |
| チラシ | くふう トクバイの店舗ページ | LINEチラシは外部から取得する手段が公開されていないため、トクバイを利用。設定の「地域のお店をトクバイで探す」から店舗ページを探して URL を登録します（3時間ごとに更新） |
| 予定 | TimeTree（Web 版の非公式 API）、iCal | TimeTree の公開 API は 2023 年に終了。Web 版と同じ方法で読み取り専用でアクセスします。仕様変更で使えなくなる可能性があります。Google カレンダーなどの iCal URL も併用できます |

外部サイトへのアクセスは PC のサーバーがまとめて行い、キャッシュします（ニュース 10〜15分、チラシ 3時間など）。

## 開発

```bash
npm run dev
```

- 画面: http://localhost:5173（Vite）／ API: http://localhost:8580（`/api` は自動でプロキシ）
- `npm test` … ユニットテスト（祝日計算、グリッド配置、各パーサー、API、全タイルを6サイズで描画するテスト、クイズデータの検証）
- `npm run lint` / `npm run typecheck` / `npm run build`

### ディレクトリ構成

```
server/            PC で動くサーバー（Express）
  app.ts           API（設定・レイアウト・共有ボード・各種データ取得・エクスポート/インポート）
  lib/             RSS・気象庁・TimeTree・iCal・チラシの解析、JSON 保存、キャッシュ
shared/            サーバーと画面で共通の型と既定値
src/
  grid/            グリッド配置ロジック・ドラッグ/リサイズ
  components/      ホーム画面、編集バー、タイル追加、設定画面など
  tiles/           各タイル（registry.ts に一覧）
  themes/          テーマ（デザイントークン）
  data/            クイズデータ
```

### タイルを追加する

1. `src/tiles/` にコンポーネントを作る（`useTileSize()` でタイルの大きさを取得し、表示を切り替える）
2. `src/tiles/registry.ts` の `TILE_DEFINITIONS` に 1 件追加（名前・アイコン・既定サイズ・最小サイズ・設定項目）

### テーマ（スタイル）を追加する

見た目はすべて CSS 変数（デザイントークン）で決まります。`src/themes/themes.ts` の `THEMES` にオブジェクトを 1 つ追加するだけで設定画面に表示されます。
壁紙は `WALLPAPERS`、タイルごとのアクセントカラーは `ACCENTS` に追加できます。
タイルの CSS は色を直接書かず、`var(--accent)` などのトークンだけを参照してください。

## CI / CD（GitHub Actions）

| ワークフロー | タイミング | 内容 |
|---|---|---|
| `ci.yml` | push（main）・プルリクエスト | Ubuntu と Windows で Lint → 型チェック → テスト → ビルド。ビルド成果物をアップロード |
| `release.yml` | `v*` タグの push | テスト・ビルドして、すぐ使える zip を GitHub Releases に公開 |
| `deploy-home-pc.yml` | main の CI 成功後 | 自宅 PC（セルフホストランナー）へ自動デプロイし、pm2 で再起動（任意・既定は無効） |

### リリースの作り方

```bash
git tag v0.1.0
```

```bash
git push origin v0.1.0
```

### 自宅 PC への自動デプロイ（任意）

1. GitHub のリポジトリ → Settings → Actions → Runners → **New self-hosted runner**（Windows）の手順で、自宅 PC にランナーを登録して起動
2. Settings → Secrets and variables → Actions → **Variables** に以下を追加
   - `HOME_PC_DEPLOY` = `true`（必須。これが無いとデプロイは実行されません）
   - `HOME_INFO_INSTALL_DIR`（任意・既定 `C:\HomeInformation\app`）
   - `HOME_INFO_DATA_DIR`（任意・既定 `%USERPROFILE%\HomeInformation\data`）
   - `HOME_INFO_PORT`（任意・既定 `8580`）
3. 以降、main に push して CI が通ると、自動で PC 上のアプリが更新されます（設定データは別フォルダなので消えません）

## トラブルシューティング

- **iPad から開けない**: PC と iPad が同じ WiFi か、Windows ファイアウォールで Node.js が許可されているか確認
- **「PC のサーバーに接続できません」と出る**: PC のサーバーが止まっています。前回の内容をそのまま表示し、復旧すると自動で再接続します
- **ポートが使用中**: `HOME_INFO_PORT=8581` のように別の番号を指定
- **チラシが出ない**: トクバイの「店舗ページ」の URL（`https://tokubai.co.jp/店名/数字`）を登録しているか確認。トクバイでチラシを出していないお店（コンビニや雑貨店など）は表示されません
- **TimeTree が表示されない**: 設定 → 予定 で「カレンダー一覧を取得」を押し、エラーメッセージを確認
